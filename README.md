# 🚀 Getting started with the Strapi Document Service Middleware Example

This is a simple example of how to use the Strapi Document Service Middleware.

## 📦 Installation

Pull the repo and run `yarn install`.

Once all the dependencies are installed, and before running the project first copy the `.env.example` file to `.env`.

Next, you need to seed the example data.

You can do this by running:

```bash
yarn strapi import -f seed-data.tar.gz --force
```

Once the data is seeded, you can run the project.

```bash
yarn develop
```
